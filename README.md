# Flipkart-Style E-Commerce Sales Analysis

## Overview
A sample e-commerce sales dataset (600 orders, Flipkart-style) analysed using 
Excel and SQL (MySQL). This project covers data cleaning, SQL queries, and an 
interactive Excel dashboard to understand sales, cancellations, and customer 
trends.

## Tools Used
- Excel (Pivot Tables, Pivot Charts, Slicers)
- MySQL (Data cleaning, Aggregate queries)

## What I Did
- Cleaned raw sales data (fixed data types, removed duplicates, handled blanks)
- Imported data into MySQL and wrote SQL queries to analyse revenue, order 
  status, and customer behaviour
- Excluded Cancelled/Returned orders from revenue calculations for accurate 
  reporting
- Built an interactive Excel dashboard using Pivot Tables, Pivot Charts, and 
  Slicers (filterable by Zone and Order Status)

## Key Insights
- West zone contributed the highest revenue (42% of total sales)
- Electronics was the top-selling category (₹71,42,700 revenue)
- Analysed order status distribution (Delivered, Shipped, Cancelled, Returned)
- Analysed payment method trends (UPI, Credit Card, COD, Debit Card, Net Banking)
